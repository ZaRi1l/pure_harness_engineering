---
name: context-curation
description: Use when an important milestone, decision, reusable lesson, or real regression has durable project value; skip routine edits and status updates.
---

Use the selected project's declared memory directory (`context.paths.memory` when a validated Node context is available; the declared management path in a portable/no-Node workflow). If no project or memory path is declared, resolve it before writing; do not assume a source-checkout directory. Update the smallest applicable file there. Preserve evidence and date/version context. Remove stale facts when superseded. Exclude transcripts, tool logs, temporary task state, speculation, and secrets.
