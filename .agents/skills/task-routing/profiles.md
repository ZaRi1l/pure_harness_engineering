# Project Profiles

Load only the profile that matches the current project work.

## Generic

Use for planning, documents, operations, and mixed work. Define observable acceptance criteria, execute the bounded task, verify the artifact, and review independently for MEDIUM/LARGE work.

## Coding

Inspect entry points and existing tests before editing. Prefer repository-supported build, test, lint, static analysis, and schema commands. Separate environment failures from product defects. Isolate independent writers with Git branches or worktrees.

## Research

Define the question, source standard, time/version boundary, and synthesis format. Prefer primary sources, record uncertainty, and verify that claims match evidence. Preserve conclusions rather than browsing transcripts.
